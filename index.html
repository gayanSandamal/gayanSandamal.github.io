AI, where it measurably pays off

I help engineering and product teams adopt AI where it actually improves delivery — design-to-code pipelines, AI-assisted development workflow and tool evaluation. I integrate and adopt AI rather than train models, and I publish numbers only when they're real.

Build — pixelflow Open Source

A Vue-first CLI that generates production components from Figma designs. An AI inference layer (Claude) classifies components and infers props; a 7-layer audit engine scores the output against the original design instead of trusting it. Apache-2.0, public roadmap, contributor-ready issues.

E/02

Enable — context engineering over prompt training

My bet for small teams: repo-level context beats prompt courses. I set up .claude/ directories with defined sub-agents and skill guides, and a CLAUDE.md orchestrator that teaches the agent the project's stack, conventions and environment quirks — so every developer's AI session starts productive instead of starting over. Running today with my own three-developer UI team; measured before/after case studies are in progress.

V/03

Evaluate — evidence before enthusiasm

Before recommending a tool, I test the claim — the same Figma file built with and without AI assistance — and I've published a teardown of where design-to-code tools, including my own, fall short of vendor promises: interpreting imperfect input and validating output.

III AI adoption

Where it measurably pays off

I help engineering and product teams adopt AI where it actually improves delivery: design-to-code pipelines, AI-assisted development workflow and tool evaluation. I integrate and adopt AI rather than train models, and I publish numbers only when they're real.

01

Build: pixelflow

A Vue-first CLI that generates production components from Figma designs. An AI inference layer (Claude) classifies components and infers props; a seven-layer audit engine scores the output against the original design instead of trusting it. Apache-2.0, with a public roadmap and contributor-ready issues.

GitHub Roadmap

02

Enable: context engineering over prompt training

My bet for small teams: repo-level context beats prompt courses. I set up agent context directories with defined sub-agents and skill guides, plus an orchestrating project brief that teaches the agent the stack, conventions and environment quirks, so every developer's AI session starts productive instead of starting over. Running today with my own three-developer UI team; measured before/after case studies are in progress.

03

Evaluate: evidence before enthusiasm

Before recommending a tool, I test the claim by building the same Figma file with and without AI assistance. I've published a teardown of where design-to-code tools, including my own, fall short of vendor promises: interpreting imperfect input and validating output.
